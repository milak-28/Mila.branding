# Mila Kalezic — Personal Branding Website

Static, responsive portfolio/branding website with logo assets and brand guide.

## Publish with GitHub Pages
1. Upload **all** files and the `assets` directory to the root of `milak-28/Mila.Kalezic.Branding`.
2. In the repository, go to **Settings → Pages**.
3. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. GitHub Pages will show the published site URL once deployed.

## Customize
Edit `index.html` to add verified experiences, projects, resume, LinkedIn, and email. Do not treat the sample interest descriptions as completed professional experience.

See `BRAND_GUIDE.md` for colors, type, logo exports, and the required reflection.


This edition includes Mila’s two original headshots and the coordinated warm-neutral/slate-blue color palette.
