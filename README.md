# Mila Kalezic — Personal Brand Website

Static, responsive personal portfolio, designed for GitHub Pages. No build step or dependencies required. Fonts load from Google Fonts; fallback fonts work offline.

## Deploy to GitHub Pages
1. Extract this ZIP.
2. Upload `index.html`, `styles.css`, `script.js`, and the complete `assets/` folder to the root of your repository: https://github.com/milak-28/Mila.Kalezic.Branding
3. Commit to `main`.
4. In GitHub repository **Settings → Pages**, select **Deploy from a branch → main → /(root)** and save.
5. Visit the Pages URL shown in settings when deployment finishes.
